## The line

> I asked my smart speaker to play something relaxing; it played my bank notifications.

One sentence, 85 characters. A familiar setup (ask the speaker for something relaxing)
with a sharp, modern twist at the end — the "relaxing" thing it plays is the one
sound nobody finds relaxing.

## How it works

`main.py` (Python 3.13, standard library only) validates the line — one line,
1–140 characters, single sentence — and writes it to `/output/entry.txt`.

```sh
python3 main.py
cat /output/entry.txt
```
